# BUG-04: POST /api/books руу буруу JSON бие илгээхэд 400 биш 200 OK буцааж байна

Орчин:  Уншлагын жагсаалт v2.0, curl (macOS), Node.js v18.20.8, 2026-11-25
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Терминал дээр `node app.js` коммандаар серверийг асаана.
2. Өөр терминал дээр дараах `curl -i` коммандаар хүчингүй JSON биетэй POST хүсэлт илгээнэ:

```bash
curl -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" -d 'буруу оролт'
```

3. Хариуны HTTP статус код болон биеийг шалгана.

Хүлээгдэж байсан: Спецификацийн 8-р дүрмийн дагуу буруу JSON биетэй POST хүсэлтэд `HTTP/1.1 400 Bad Request` алдааны статус код буцаана.
Бодит үр дүн:     Сервер `HTTP/1.1 200 OK` статус код болон `{"result":"OK"}` хариу буцааж, буруу JSON хүсэлтийг алдаа гэж барьж авахгүй байна.

Ноцтой байдал: Major — API түвшний оролтын баталгаажуулалт ажиллахгүй, буруу бүтэцтэй хүсэлтийг амжилттай мэт хүлээн авч байгаа нь өгөгдлийн бүрэн бүтэн байдалд эрсдэлтэй.
