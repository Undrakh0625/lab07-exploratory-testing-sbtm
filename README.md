## Дүгнэлт (Хэсэг E)

Энэхүү 60 минутын exploratory тестийн сессийн явцад Fed-Ex Tour (Business District) болон Antisocial Tour (Seedy District) гэсэн хоёр өөр дүүргийн аялалыг хослуулан ашигласан нь маш үр дүнтэй байлаа. Тухайлбал, номын өгөгдлийн урсгал болон үндсэн хүснэгтийг шалгасан Fed-Ex аялалын үеэр «Он» багана мянгатын таслалтай харагдах (`BUG-01`) болон «Устгах» товч улаан биш ногоон өнгөтэй байх (`BUG-02`) зэрэг UI согогуудыг илрүүлсэн. Харин дүрэм зөрчсөн оролт ба хуудасны холбоосуудыг сорьсон Antisocial аялалын үеэр «Хуучин хувилбар» линк дээр дарахад `Internal Server Error (500)` заах (`BUG-03`) болон `curl -i` ашиглан `POST /api/books` руу эвдэрсэн JSON бие илгээхэд `400 Bad Request`-ийн оронд `200 OK` буцаадаг (`BUG-04`) ноцтой согогуудыг баталгаажуулав. Charter-аас гадуур ажиглахад хүснэгтийн доорх «Нийт ном» тоолуур бодит мөрийн тооноос зөрүүтэй байх шинж тэмдэг, мөн том/жижиг үсэг ялгах хайлт, давхардсан ном бүртгэх хилийн тохиолдлууд бүрэн шалгагдаагүй үлдсэн тул дараагийн сессийн charter-т оруулах шаардлагатай. Илрүүлсэн эдгээр согогоос `BUG-04` (API HTTP статус код `400` vs `200`) болон `BUG-03` (`/old` хуудасны HTTP `500` алдаа) нь тодорхой статус код шалгадаг тул Playwright автомат тестээр хялбар баригдах боломжтой. Харин `BUG-02` («Устгах» товч аюултай үйлдэл атлаа ногоон өнгөтэй байж хэрэглэгчийг төөрөгдүүлэх) болон `BUG-01` (онууд `1,999` гэж таслалтай харагдах визуал таагүй байдал) нь хүний нүд, UX мэдрэмжээр хамгийн түрүүнд анзаарагдах согогууд байв.
