## Хэсэг E — Нэгдсэн дүгнэлт ба шинжилгээ

### 1. Аялалуудын (Tours) үр нөлөө
Энэхүү 60 минутын exploratory тестийн сессийн явцад **Fed-Ex Tour** (Business District) болон **Antisocial Tour** (Seedy District) гэсэн хоёр өөр дүүргийн аялалыг хослуулан ашигласан нь маш үр дүнтэй байлаа. Хэрэглэгчийн хэвийн өгөгдлийн замыг дагасан Fed-Ex аялалын үеэр хүснэгтийн «Он» багана мянгатын таслалтай харагдах (`BUG-01`), «Устгах» товч ногоон өнгөтэй байх (`BUG-02`), мөн «Нийт ном» тоолуур бодит мөрийн тооноос 1-ээр илүү тоолох (`BUG-05`) зэрэг UI болон статистик тооцооллын согогуудыг илрүүлсэн. Харин дүрэм зөрчсөн, эвдэрхий оролт ба хуудасны холбоосуудыг сорьсон Antisocial аялалын үеэр «Хуучин хувилбар» линк `500 Internal Server Error` заах (`BUG-03`), `POST /api/books` руу буруу JSON бие илгээхэд `400 Bad Request`-ийн оронд `200 OK` буцаах (`BUG-04`), болон хоосон талбар, `21002` гэсэн хязгаараас хэтэрсэн он зөвшөөрөгдөх (`BUG-06`) ноцтой согогуудыг баталгаажуулав.

### 2. Автомат тест vs Хүний exploratory тест
- **Автомат тестээр (Playwright / API тест) хялбар баригдах согогууд:** `BUG-03` (`/old` хуудасны HTTP `500` статус код), `BUG-04` (`POST /api/books` буруу JSON-д `400` биш `200` буцаах), `BUG-05` («Нийт ном» тоолуурын математик зөрүү), болон `BUG-06` (хоосон талбар ба `21002` он оруулахад алдааны мессеж гарахгүй байх) зэрэг нь тодорхой утга, DOM элемент болон HTTP статус код шалгадаг тул автомат регресс тестээр найдвартай баригдана.
- **Хүний exploratory тестээр илүү сайн илрэх согогууд:** `BUG-02` («Устгах» товч аюултай үйлдэл атлаа ногоон өнгөтэй байж хэрэглэгчийг төөрөгдүүлэх) болон `BUG-01` (онууд `1,971`, `2,008` гэж мянгатын таслалтай харагдах визуал таагүй байдал) нь функциональ хувьд ажиллаж байгаа ч хүний нүд, UX мэдрэмжээр хамгийн түрүүнд анзаарагдах согогууд байв.

### 3. Дараагийн сессийн Charter-ийн санал
Энэ сессийн төгсгөлд (20:14) ажиглагдсан боловч цагийн хязгаараас шалтгаалан бүрэн баталгаажуулж амжаагүй дараах чиглэлүүдээр дараагийн 60 минутын **Supermodel Tour** болон **Bad Neighborhood Tour** сесс хийх саналтай байна:
1. **Хайлт ба тэмдэгт кодчилол:** Жижиг үсгээр (`clean`) хайхад `Clean Code` олдохгүй байгаа том/жижиг үсэг ялгах алдаа, мөн `&`, `<`, `>` зэрэг HTML тусгай тэмдэгтүүд давхар escape (`&amp;`) болж харагдаж буй эсэхийг шалгах.
2. **Давхардал ба устгах үйлдлийн мессеж:** Ижил гарчиг, зохиолчтой ном давхардуулж нэмэх хилийн тохиолдол болон ном устгасны дараа дэлгэц дээр гарах мэдэгдлийн текст («Ном нэмэгдлээ» гэж буруу гарч буй эсэх)-ийг шалгах.
